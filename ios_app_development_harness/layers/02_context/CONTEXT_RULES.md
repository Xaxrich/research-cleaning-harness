# CONTEXT RULES

## Default

Load only task-relevant context.

## Search Before Read

Use search to locate candidates before opening many files.

## View Before Edit

Inspect the target region before changing a file.

## Product Before Plan

Before implementation work, read the confirmed product brief and solution plan. If either is missing, stop and create a discovery or planning task.

## Plan Before Task

For multi-module work, read `TASK_BREAKDOWN.md` before editing `TASKS.md`. Do not invent task order inside an implementation task.

## Raw / Research Boundary

This standalone harness should not require research files at runtime.
